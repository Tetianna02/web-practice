## Виправлення нових сторінок

- Login/Signup: текст акції та посилання об'єднані в окрему групу. На desktop група в центральній колонці з однаковими бічними колонками, перемикач мови праворуч. На мобільному повідомлення переноситься й центрується. Виміряна різниця центру групи від центру viewport — менше0,1px на всіх перевірених ширинах.
- Правила пари «Вхід / Реєстрація» додані **тільки в auth-pages.css** із `.auth-page`. Загальні стилі Home не змінювалися.
- 404 зберігає абсолютні шляхи `/web-practice/assets/...` і повернення `/web-practice/index.html`, потрібні для вкладених URL GitHub Pages.
- У BAT змінена тільки команда запуску: новий невеликий preview-сервер підтримує одночасно `/` та `/web-practice/`, віддає власну404 з HTTP404. Він **не переписує HTML/CSS/JS і URL ресурсів**: HTTP-вміст Home дорівнює файлу index.html. Сервер доступний лише на127.0.0.1; повторне зайняття порту заблоковане. Main-верстка не залежить від цього доповнення.
