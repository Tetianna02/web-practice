# Крок 3: вимоги курсової для Home

Дата: 25.10.2026. Обсяг: лише Home, без реалізації інших сторінок, backend чи БД. Базовий стан до змін — коміт `da075fe`. Figma не використовувалася; сімейства, ваги, розміри шрифтів та зображення PS5 залишені без змін.

## Зміни

- Додано CSS Sprite `assets/images/icons/service-icons-css-sprite.svg`: атлас 120×40 з трьома фрагментами 40×40. Джерела — наявні `icon-service-delivery.svg`, `icon-service-support.svg`, `icon-service-shield.svg`. Атрибути всіх контурів збережені; ідентифікатори clipPath отримали префікси для уникнення конфліктів. CSS показує потрібний фрагмент через `background-position`. Це покриває загальний пункт 7; наявний `sprite.svg` не змінено.
- Таймери отримали фіксовані демонстраційні строки: розпродаж — `2026-11-30T23:59:59+02:00`, JBL — `2026-12-31T23:59:59+02:00`. Строки задані у `data-countdown-end`; старі значення localStorage не використовуються. Після завершення показується повідомлення, інтервал зупиняється. Некоректна дата обробляється без збою JavaScript.
- Для кошика, обраного й відсутніх сторінок використано єдиний текст toast: «Буде доступно на наступному етапі». «Про нас» і «Контакти» більше не маскують відсутню сторінку переходом до секції Home. Посилання на наявні секції збережені.
- Кнопка «Вхід» відкриває режим входу. Валідна демонстраційна форма повідомляє про майбутнє підключення авторизації; дані не надсилаються на сервер і акаунт не створюється.

## Перевірки та докази

Локальна автоматизована перевірка: **38/38 успішні** у Microsoft Edge, desktop 1440 px. Адреса `http://127.0.0.1:4173/web-practice/` відтворює очікуваний префікс GitHub Pages. Це не підтверджує фактичну публікацію в Інтернеті.

Перевірено метатеги, заголовки, label/type, alt, defer, якорі, шрифти без змін, обидва спрайти, favicon, toast і базову валідацію демонстраційних форм. Таймери перевірено зі старими значеннями localStorage, після reload, в іншому часовому поясі, за секунду до дедлайну, на межі завершення, після обох дедлайнів і з некоректною датою. Від'ємних значень і відновлення завершеної акції після reload немає. Формами не виконано POST чи інших запитів зміни даних; alert не викликався.

Додатково: `node --check assets/js/main.js` та `git diff --check` успішні. Візуально переглянуто три іконки CSS Sprite та стан завершеної акції.

## Межа цього кроку

Крок 4 не розпочато. Ширини 320/360/768/1024, довгі назви, відсутні картинки, різна кількість карток, burger і повне приймання модалки (закриття, фон, Esc) залишаються для нього. W3C, Jigsaw, PageSpeed і повна браузерна матриця ще не виконувалися; це не замінено локальними перевірками. Кроки 5 і 6, публікація та інші сторінки не виконувалися.

Для приймання: відкрийте Home через свій `start-server.bat`, натисніть Ctrl+F5, перевірте іконки переваг, кошик/обране/«Про нас»/«Контакти» та обидва таймери. Наступна дія — лише після відповіді користувачки.
