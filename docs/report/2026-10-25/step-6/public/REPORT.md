## Що перевірено

- 28 img у сформованій сторінці завантажені й мають alt; перевірено всі п'ять hero-слайдів. Для повного обходу тест явно завантажив lazy-зображення. Це функціональна перевірка ресурсів, не вимір першого завантаження.
- Шість локальних WOFF2 успішно завантажені; Google Fonts не використовується.
- SVG Sprite: 149 видимих use на desktop, 147 на mobile; порожніх геометрій немає. Сердечка, око, стрілки, категорії та рейтинги працюють. 22 різні fragment IDs існують із точним регістром. Три CSS Sprite-фрагменти мають фон і ненульові розміри.
- Мобільне меню: пошук, навігація, дев'ять категорій, Esc, повернення фокусу. На desktop навігація доступна без burger.
- Модалка: відкриття, реєстрація/вхід, валідація, фокус на помилці, клавіатурне перемикання вкладок, закриття кнопкою/фоном/Esc, повернення фокусу. Перевірені клієнтські демонстраційні форми; реальних акаунтів чи запитів авторизації ще немає.
- Пошук ASUS, скидання до 18 карток, placeholder toast, клавіатурні Home/End стрічок, якорі, заголовки, ARIA, відсутність горизонтальної прокрутки документа.

## Перевірка опублікованих файлів

[deployed-assets.json](deployed-assets.json): **41 унікальний файл**, усі **HTTP 200**, усі SHA-256 **точно збігаються з файлами коміту HEAD**. Це включає index, обидва CSS, JS, шрифти, favicon, обидва спрайти, WebP/PNG/SVG. Отже, Pages віддає поточні закомічені ресурси без втрати `_variables.css`.

У початковій допоміжній перевірці порівняння з робочими файлами Windows показало різні байти для текстових файлів: CRLF на диску проти LF у Git. Порівняння виправлено на Git blobs; жодної зміни в сайті для цього не потрібно. Унікальні файли відокремлено від 22 SVG fragment-посилань, які не є окремими мережевими файлами. Підсумковий JSON містить правильне порівняння та сирі хеші.
