## Локальний сервер

Додано `start-server.bat` у корінь `web-practice`. Він переходить у власну папку через `%~dp0`, перевіряє наявність Python 3 (`py -3`, потім `python`) і запускає стандартний статичний HTTP-сервер на `127.0.0.1:8000`. Залежності не встановлюються, доступ з інших комп'ютерів не відкривається. Це інструмент перегляду frontend, не backend курсової.

Перевірено фактичним запуском `cmd /d /c start-server.bat`. У вікні виводиться українська інструкція та адреса `http://127.0.0.1:8000/`; сервер віддає Home й ресурси.

Як користуватися: двічі натиснути BAT у Провіднику, відкрити зазначену адресу, тримати вікно сервера відкритим. Після змін Ctrl+F5. Для завершення закрити вікно сервера або натиснути Ctrl+C. Повна коротка інструкція є в README.md.

При відкритті через file:/// браузер може блокувати посилання use на зовнішній SVG. Через HTTP усі ресурси мають спільне походження, тому Sprite працює без вставлення копій SVG у HTML і без заміни іконок.

## Знайдена причина горизонтальної смуги

Елемент-порушник: `.horizontal-product-list` у розпродажі. Попередня формула:

```css
width: calc(100% + (100vw - var(--container-width)) / 2);
```

`100vw` включало вертикальну системну смугу, а центрований контейнер розраховувався за доступною шириною контенту. У Windows браузер залишав праворуч 15–17 px для вертикальної прокрутки; половина цієї різниці давала приблизно 8 px переповнення.

Реальні виміри до виправлення:

| Вікно | Вертикальна смуга | clientWidth | scrollWidth | Правий край стрічки |
|---|---:|---:|---:|---:|
| 1440 | 15 | 1425 | 1433 | 1432,5 |
| 1440 | 17 | 1423 | 1432 | 1431,5 |
| 1920 | 15 | 1905 | 1913 | 1912,5 |
| 1920 | 17 | 1903 | 1912 | 1911,5 |

Попередня перевірка кроку 2 приховувала системні смуги в headless-браузері; тому не виявила цей випадок. Поточні перевірки явно залишають системну прокрутку видимою.

Виправлення в desktop-правилах:

```css
.flash-section {
  container-type: inline-size;
}

.horizontal-product-list {
  width: 100%;
  width: calc(50% + 50cqw);
}
```

`cqw` вимірює ширину реальної секції, а не viewport разом зі смугою. Стрічка доходить до правого краю доступного контенту; її внутрішня прокрутка зберігається. 100% є резервом для браузерів без підтримки нового розрахунку. Глобальне overflow-x: hidden/clip для приховування проблеми не додавалося. Футер і банери не були причиною, їх не змінювали.

## Результати перевірки

Пройдено **8/8** комбінацій: локальний корінь та префікс `/web-practice/`, ширини вікна 1440/1920, нативна смуга 15 px та примусова 17 px.

| Вікно | Вертикальна смуга | clientWidth | scrollWidth після виправлення | Скрол сторінки вбік |
|---|---:|---:|---:|---|
| 1440 | 15 | 1425 | 1425 | Немає |
| 1440 | 17 | 1423 | 1423 | Немає |
| 1920 | 15 | 1905 | 1905 | Немає |
| 1920 | 17 | 1903 | 1903 | Немає |

Для обох адрес та всіх чотирьох геометрій:

- `window.scrollTo(9999, 0)` залишає scrollX=0.
- Внутрішня стрічка товарів прокручується.
- Немає видимих елементів, що виходять за межі сторінки. Навмисно візуально приховане accessibility-посилання skip-link не вважається помилкою переповнення.
- Усі 38 запитаних ресурсів із assets успішно завантажені; усі 6 WOFF2 завантажені локально.
- Sprite повертає HTTP 200; усі використані ID символів знайдені.
- Зображення завантажені, немає JavaScript/console-помилок, збоїв мережі та запитів поза очікуваним префіксом.
- Висота сторінки лишилася 5902 px.

Окремо збережені 11 растрових зразків намальованих браузером SVG: шість категорій, сердечко, око, рейтинг і дві стрілки. Для всіх зразків підтверджено, що вони не порожні. [Іконки через HTTP із префіксом Pages](icons-proof.png).

## GitHub Pages

Адреса `http://127.0.0.1:4173/web-practice/` у перевірці імітувала структуру шляху майбутньої публікації. HTML/JS/SVG/зображення отримані через `/web-practice/assets/...`, CSS-шрифти — через `/web-practice/assets/fonts/...`. Посилання на Sprite залишаються відносними й працюють при такому префіксі.

Це перевірка шляхів, а не реальне розгортання GitHub Pages. Публікація й налаштування GitHub будуть у кроці 6 після окремого продовження. Усі потрібні поточні ресурси assets уже є в Git; нових production-зображень або шрифтів у цьому уточненні не додавали.

## Типографіка збережена

Порівняння `style.css` з комітом 351e87b підтвердило, що всі **209** оголошень font/font-family/font-size/font-weight/font-style/font-display/line-height/letter-spacing/unicode-range збережені. `_variables.css` та файли WOFF2 не змінювалися. Поточна типографіка прийнята користувачкою як джерело, повторних викликів Figma не було.

| Шрифт | Вага | Де використовується |
|---|---|---|
| Poppins Regular | 400 | Базовий текст, латинські фрагменти меню, підписи та iPhone 14 Series |
| Poppins Medium | 500 | Назви товарів, ціни, кнопки й посилання, частина заголовків футера |
