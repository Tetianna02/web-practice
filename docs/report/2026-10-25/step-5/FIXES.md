# Виправлені помилки Home

Дата: 25.10.2026. Початковий коміт: `d3ad2ce` (погоджений крок 4).

| Причина | Де | Виправлення | Доказ |
|---|---|---|---|
| aria-label на звичайному div без семантичної ролі | Пагінація hero | Додано role="group" | nu-source-before.json → nu-source-after.json |
| aria-label на звичайному div без семантичної ролі | Соціальні кнопки футера | Додано role="group" | Ті самі відповіді Nu |
| role="tabpanel" не дозволена для form | Модальна форма | Створено зовнішній div-панель; form зберігає власну семантику. aria-controls вкладок посилається на панель, JS оновлює aria-labelledby панелі | Вихідний HTML і обидва відкриті режими модалки: 0 помилок |
| aria-label на звичайному span, 18 повторень | Рейтинг створених JS товарних карток | У createProductCard додано role="img" для спільного зображення рейтингу; окремі SVG-зірки лишаються aria-hidden | nu-*-dom-before.json → nu-*-after.json |

Це **чотири причини**, з яких перші три видно у вихідному HTML, а останню — тільки після виконання JavaScript. Структура, семантичні ролі та зв'язок вкладок виправлені без зміни CSS, зображень, шрифтів чи асортименту.

Після виправлень: 6 перевірок Nu — по 0 помилок/попереджень; 80/80 локальних перевірок у Chrome/Edge. Повторно перевірено меню, режими/валідацію форми, Esc/кнопку/фон, повернення фокусу, пошук і повідомлення-заглушки.

CSS під попередження Jigsaw не переписувався. Сервісні HTTP 500 перших запитів були пов'язані зі способом надсилання: офіційна форма Jigsaw використовує multipart. Після переходу на нього отримано справжню SOAP-відповідь HTTP 200. Це виправлення перевірочного скрипту, не помилка коду Home.
