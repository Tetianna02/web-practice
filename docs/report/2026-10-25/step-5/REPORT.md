# Крок 5: перевірки Home для звіту

Доповнення за наступним запитом користувачки: **Firefox 153.0 і WebKit 26.5 — 84/84 перевірки** на 360/1440 px, без JS/Console/Network помилок. Повні журнали й знімки: [cross-browser/REPORT.md](cross-browser/REPORT.md). Нижче збережена початкова серія Chrome/Edge. WebKit не прирівнюється до перевірки Safari.

Дата: **25.10.2026**. Погоджений крок 4 збережений комітом **d3ad2ce**. Крок 5 виконаний у межах Home; публікація, інші сторінки, backend, БД та Figma не виконувалися. Крок 6 очікує окремого «далі».

## Виправлення HTML/JS

Перший Nu-запит для вихідного HTML показав три помилки: aria-label на двох звичайних div та недозволений role=tabpanel у form. Додано group для пагінації hero/соціальних кнопок; панель вкладок винесено у зовнішній div із правильними ARIA-зв'язками.

Після цього перевірка сформованого DOM показала 18 повторень іншої помилки — aria-label на звичайному span рейтингу. Додано role=img у єдиній функції генерації товару. Окремі SVG-зірки приховані від допоміжних технологій, а спільний рейтинг має текст «Оцінка ... з 5».

Повний перелік: [FIXES.md](FIXES.md). CSS, сімейства/ваги/розміри шрифтів та зображення на цьому кроці не змінювалися. Старі діагностики й DOM збережені окремо, фінальна папка — `dom/`.

## Jigsaw: діагностики й пояснення

Обидва CSS, підключені саме до Home, надіслані в [Jigsaw](https://jigsaw.w3.org/css-validator/) як multipart-текст. Використано профіль **css3svg**, носій **all**, рівень попереджень **2** та офіційний [SOAP API](https://jigsaw.w3.org/css-validator/api.html). Первинна пісочниця блокувала socket; дозволений доступ поза нею працював. Перші спроби не у форматі multipart отримали HTTP 500; ці записи залишені як технічний журнал, а не результати валідації CSS. Фінальні запити повернули HTTP 200 і справжню XML-відповідь.

|---|---|---|

| 1084 | .explore-section > .container | Профіль не розпізнає container-type |

| 2592 | .flash-section | Не розпізнаний container-type |
| 2695 | .horizontal-product-list | Parse Error для calc(50% + 50cqw) |

Це висновок про обмеження перевірочного профілю, а не перейменування його errors на warnings. Докази: усі відповідні CSS.supports-перевірки, включно з виразами **без var()**, дали true у двох браузерах; компоненти мають обчислені розміри й працюють. Збережено [extra-resources.json](extra-resources.json), а сирі повідомлення лишилися в [jigsaw-style-after.xml](jigsaw-style-after.xml) / JSON.

Математичні функції описані у [CSS Values and Units Level 4](https://www.w3.org/TR/css-values-4/#math); container-type та cqw — у [CSS Containment Level 3](https://www.w3.org/TR/css-contain-3/#container-lengths). Це сучасні модулі CSS; їхню підтримку старішим профілем сервісу не слід прирівнювати до підтримки браузером. Без потреби змінювати погоджену верстку через ці повідомлення не стали.

Перевірено встановлені **Chrome 155.0.8059.85** та **Edge 156.0.4314.42** у headless-режимі на viewport 360/1440 px. Для кожного запуску є HAR без тіл відповідей, журнал runtime.json і скриншоти. Адреса — `http://127.0.0.1:4173/web-practice/`, тобто очікуваний префікс Pages відтворено локально.

## Посилання, регістр і Git

Усі внутрішні якорі мають цільові id. У manifest — **63 записи URL, 41 унікальний файл**: HTML/JS/CSS, усі використані зображення, шість WOFF2, favicon, SVG Sprite та CSS-атлас. Кожну частину шляху порівняно з точними назвами каталогу на диску, не лише через case-insensitive exists Windows. Розбіжностей немає, усі 41 файли відстежуються Git.

Для SVG use перевірено **22 унікальні fragment IDs** із точним регістром. У двох браузерах по **149 видимих use** мають ненульові розміри. Три CSS Sprite-фрагменти підключені; внутрішні clipPath атласу знайдені. Файли: [resources.json](resources.json), [extra-resources.json](extra-resources.json).

mailto/tel перевірені як посилання демонстраційних контактів; надсилання пошти чи дзвінок не виконувалися. Відсутні сторінки оформлені кнопками з toast, а не несправними href. about.html/contact.html не відновлювалися. Перевірка префікса локальна, вона не означає фактичної публікації.
