# Доповнення кроку 5: Firefox і WebKit

Дата: 25.10.2026. Перевірено поточну Home після прийнятого кроку 5, без змін HTML/CSS/JS сайту.

**84/84 перевірки успішні.** Використано Playwright 1.62.1, Firefox 153.0 (revision 1538) та WebKit 26.5 (revision 2336) на Windows.

|---|---|---|---|---|---|---|

| Firefox | 360 px | 42 | 0 | 0 | 0 | 147 |
| WebKit | 1440 px | 40 | 0 | 0 | 0 | 149 |
| WebKit | 360 px | 40 | 0 | 0 | 0 | 147 |

Console-журнали в цих чотирьох запусках порожні. Збоїв завантаження, HTTP 4xx/5xx і горизонтальної прокрутки документа немає. Всі 28 img завантажені з alt; шість локальних WOFF2 перевірені явним завантаженням. Усі п'ять hero-слайдів відкриті. Потрібні сучасні CSS-вирази приймаються обома рушіями.

Додатково перевірено:

- мобільне меню: пошук, навігація, 9 категорій, Esc і повернення фокусу;
- модальне вікно: відкриття, обидва режими, label/type, помилки порожніх полів, стрілки вкладок, зв'язок tabpanel, закриття кнопкою/фоном/Esc, повернення фокусу;
- пошук ASUS і скидання пошуку до 18 карток;
- placeholder toast, Home/End стрічок, заголовки, ARIA-посилання й унікальність id;
- SVG Sprite: ненульова геометрія всіх видимих use, 22 унікальні fragment IDs із точним регістром;
- три CSS Sprite-фрагменти, шляхи, точний регістр і Git-покриття ресурсів.

Файли: [browser-audit.json](browser-audit.json), `*-runtime.json`, `*.har`, `dom/`, `*-home.png`, `*-menu.png`, `*-modal.png`. HAR не містять тіл відповідей. [audit-cross-browser.cjs](audit-cross-browser.cjs) відтворює перевірку через окремий статичний сервер 4173 з префіксом `/web-practice/`.

Знімки 1440 px збережені як full-page, мобільні стани меню/модалки — окремими viewport-знімками. Візуально переглянуто WebKit-модалку й Firefox-меню; форма, іконки та видимі помилки відображаються. Відмінності згладжування шрифтів між рушіями не видаються за помилки ресурсів.

Перший запуск Firefox усередині обмеження дочірніх процесів пісочниці не створював сторінку; тест повторений із дозволеним запуском поза цим обмеженням. Налаштування безпеки браузерів не вимикалися. Перевірка очікує complete/naturalWidth зображень, а не необмежено очікує decode прихованих/лінивих зображень.

**WebKit Playwright — це тест рушія, не встановлений Safari і не iPhone.** Safari на пристрої Apple цим звітом не підтверджується. З урахуванням попереднього кроку тепер є перевірки Chrome, Edge, Firefox і WebKit; повна курсова вимога про Safari ще потребує окремої перевірки або чесного зазначення обмеження.

Тестові браузери встановлені у локальний кеш Playwright поза репозиторієм; їхні завантаження не збільшують Git і не потрапляють у Pages.
