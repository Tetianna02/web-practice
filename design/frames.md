# Фрейми Figma

Файл: `ous448jLim7yOyJdNiACkP` — Untitled--Copy.

Figma MCP повернув структуру сторінки `0:1` і назви деяких фреймів, але вичерпав ліміт Starter під час наступних запитів. Тому нижче розділено підтверджені відповідності та node-id, назви яких ще треба звірити. Невідомі відповідності навмисно не вгадую.

## Підтверджені фрейми

| Екран | Node ID | Підтверджена назва у Figma |
|---|---:|---|
| Home | `1:1108` | E-Commerce HomePage |
| Category | `1:1299` | Category Dropdown |
| About | `1:1925` | About |
| Contact | `1:1990` | Contact |
| Product | `1:2022` | Product Details page |

## Екрани, що очікують звірки назви

У наданих посиланнях також є такі node-id. Їхні назви не вдалося підтвердити після ліміту Figma MCP:

| Очікуваний екран | Node ID з наданого посилання | Статус |
|---|---:|---|
| Поки не визначено | `1:1495` | Надане посилання, назва не підтверджена |
| Поки не визначено | `1:1698` | Надане посилання, назва не підтверджена |
| Поки не визначено | `1:1730` | Надане посилання, назва не підтверджена |
| Поки не визначено | `1:1754` | Надане посилання, назва не підтверджена |
| Поки не визначено | `1:1780` | Надане посилання, призначення не підтверджене |
| Поки не визначено | `1:1790` | Надане посилання, назва не підтверджена |
| Поки не визначено | `1:1808` | Надане посилання, назва не підтверджена |
| Поки не визначено | `1:1883` | Надане посилання, назва не підтверджена |

Із запитаних екранів окремо лишилися непідтвердженими: Sign Up, Log In, Account, Wishlist, Cart, Checkout і 404. Не можна надійно розподілити ці назви між node-id без доступу до їхніх metadata.

Посилання з node-id `1:1108`, `1:1495`, `1:1299`, `1:1925`, `1:1990` і `1:2022` надійшли від користувачки. Для завершення списку потрібен повторний доступ Figma MCP або експорт переліку фреймів з Figma.
